Chorus × opencode 接入包（Windows）
====================================

前提：本机已安装 Node 20+ 和 opencode（终端能跑 opencode 即可）。
本包是平台定制版守护进程（官方 npm 包没有 opencode 后端，别用官方包替换）。

三步走
------
1) 双击 一键安装.bat
   - 自动配置 opencode（模型、Chorus 平台接入、AGENTS.md 工作规范；
     已有 opencode.json 会先备份 .bak，模型配置不动）
   - 先确认平台地址（直接回车用默认 http://10.0.4.14:8637，也可输入自定义地址）
   - 再输入平台 API Key（浏览器开平台网页 → 新建智能体 → 复制 cho_ 密钥）
   - 自动设置默认工作目录（有 D 盘则 D:\opencode-auto-work，否则用户目录下同名文件夹）

2) 双击 启动守护进程.bat
   - 守护进程转入后台（无常驻黑窗口），并自动打开本地控制台：
     http://127.0.0.1:8638 （仅本机可访问）
   - 页面上可以：增删目录白名单（保存并重启生效）、看在线状态/任务队列/日志、
     一键重启或停止守护进程

3) 可选：双击 开启开机自启.bat
   - 以后每次登录 Windows，守护进程自动在后台启动（无窗口、不弹浏览器）
   - 取消：双击 关闭开机自启.bat

验证是否通了
------------
平台上给这台机器的智能体派个小任务，约 1 分钟内它会自动执行，
看板卡片自动推进到"待验证"；本地控制台的日志区能看到全过程。

排障
----
- 控制台打不开：守护进程没在跑，先双击 启动守护进程.bat
- 提示找不到 opencode：设置环境变量 CHORUS_OPENCODE_PATH 指向 opencode.exe
  完整路径（终端 where opencode 可查）
- 登录失败：确认浏览器能打开 http://10.0.4.14:8637，key 别带空格
- 命令行方式（本目录 cmd）：chorus.bat daemon status / logs / stop
- 换模型：编辑 %USERPROFILE%\.config\opencode\opencode.json 的 model 项
